# Monthly Water Bill Estimator

A Java program that estimates a monthly water bill based on water consumption and classifies usage levels.

## Description

This project was developed to practice fundamental programming concepts in Java. It uses variables, arithmetic operators, boolean expressions, conditional structures, methods, and user input with `Scanner`.

The program asks for the customer's name and monthly water consumption. Then it determines whether the consumption is **Low**, **Normal**, or **High**, calculates the bill, and displays a recommendation message.

## Features

- Reads customer name and water consumption
- Validates user input
- Classifies consumption level
- Calculates base bill
- Applies surcharge for high consumption
- Displays a final summary
- Uses methods for better code organization

## Example

**Input:**
- Customer name: Laura
- Monthly water consumption: 28

**Output:**
- Category: High
- Base bill: $70000.0
- Surcharge: $15000.0
- Total bill: $85000.0
